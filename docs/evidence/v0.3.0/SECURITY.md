# Security notes for Adapter v2 and Stillness

## Credential domains

- **Adapter device token** is generated by `AuthService`, shown once to the
  client, and stored as SHA-256 in adapter SQLite. The raw token appears only in
  the pairing response and the client credential store.
- **Browser preview** uses `localStorage`, labelled as preview/test storage in
  Settings. It is not a keystore and is not described as one.
- **Tauri** uses `keyring` for the secret and keeps only account names and the
  active server URL in the app config directory. The metadata file is written
  mode `0600` on Unix. Read/delete failures surface as errors instead of being
  treated as an empty store.
- **Command Code provider credentials** are JCode's domain. The adapter never
  reads, proxies, logs, returns, or stores them. `ListModels`/`GetRuntimeInfo`
  are the only source of provider and route state.

## Pairing

- Pairing codes expire after ten minutes, are single-use, and are compared via
  hashes in SQLite.
- Failed pairing attempts are rate-limited per peer IP.
- The pairing code supplied through `JCODE_ADAPTER_PAIRING_CODE` exists for
  controlled deployment and isolated tests; the default is a generated
  single-use code printed once on startup.
- Revocation closes existing WebSocket connections for that device.
- Native Tauri webview origins (`tauri://localhost`,
  `http(s)://tauri.localhost`) are accepted in addition to loopback origins.
  Bearer authentication is still required. Remote browser origins require
  `JCODE_ADAPTER_ALLOWED_ORIGINS`.

## Transport

The adapter binds loopback by default. Exposing it beyond loopback requires
TLS or an authenticated private tunnel (for example Tailscale) with a reviewed
trust policy. This repository does not implement a TLS terminator, VPN client,
or SSH client for the phone.

## Filesystem

- Every project is canonicalized under configured allowed roots.
- Relative paths containing `..`, absolute paths, NUL bytes, and paths escaping
  the root are rejected before any read.
- Symlinks are shown but never traversed when the target leaves the root.
- `.jcode`, `.ssh`, `.aws`, `.gnupg`, `.netrc`, `.env*`, private keys, and
  Command Code account files are hidden and rejected.
- Folder creation accepts one safe segment, rejects collisions, and verifies
  the created canonical path is still under the root.
- The browser never writes file contents or executes files.

## Operations

- A message is `dispatching` when the adapter has written it. `accepted` only
  follows an authoritative `MessageAccepted` event.
- Five seconds without an acknowledgement becomes `unknown`; a late
  acknowledgement can promote `unknown` to `accepted`, but the client never
  automatically resends.
- Duplicate reserve/dispatch requests are idempotent. Crash recovery moves
  in-flight operations to `unknown`.
- Navigation, backgrounding, socket close, and app shutdown never send
  `operations.cancel`. Only the explicit Stop control does, scoped to one
  session and verified against the expected turn.
- A `NeedsReconcile` event from a stream gap triggers a snapshot, not invented
  messages or completion.

## Logging

The adapter logs connection counts, errors, and session ids. It does not log
pairing codes, bearer tokens, request bodies, provider keys, or file contents.
