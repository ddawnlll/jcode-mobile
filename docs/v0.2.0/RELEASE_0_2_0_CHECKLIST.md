# v0.2.0 acceptance checklist

These are required checks, not claims of passing implementation.

- [ ] Preserve original Tidal Light/Night colors and existing user appearance; add ten complete family sets and independent System/Light/Night mode.
- [ ] Persist theme, appearance, effects and reasoning-display preferences; verify they affect actual render sites after restart.
- [ ] Ship welcome and live theme/material preview with immediate usable actions.
- [ ] Ship the native pending-only loading animation; paint cache first; stop on success/error; keep long-wait recovery and navigation usable.
- [ ] Add glass composer/menus/context with bounded blur regions, documented Android blur target, opaque fallbacks, Reduce Transparency and Reduce Motion.
- [ ] Provide Projects and a genuine authenticated remote folder picker with canonicalization, paging and useful errors.
- [ ] Expose real model/effort selection; verify effective values before sending the first instruction; recover partial configuration failures safely.
- [ ] Provide Context with authoritative used/limit/basis/freshness; independently handle unknown/stale fields; do not substitute billing totals or generic model limits.
- [ ] Provide Hidden/Compact/Expanded reasoning, Compact by default, over server-exposed content only; no provider or execution change when toggled.
- [ ] Provide shared inline/Work tool-call renderers with typed inputs/results, unknown-tool fallback, actual lifecycle status, exact copy and honest truncation.
- [ ] Provide CommonMark/GFM, real syntax highlighting and offline inline/display LaTeX; pass the mixed-content/streaming/malformed corpus.
- [ ] Prove session restoration, continuation on disconnect, reading anchor, delivery uncertainty, rollback and late-event fences remain correct.
- [ ] Retest relevant review regressions; close or explicitly characterize remaining F16 Work-memory/virtualization, F20 registry coordination and F22 native focus/accessibility limits.
- [ ] Verify 320-wide reflow, 200% text, keyboard-safe actions, Android Back/edge-to-edge and iOS safe areas.
- [ ] Run TalkBack/VoiceOver, native reduced effects/motion, real device startup/memory/scroll profiling and live server integration.

The HTML, reference boards and GIF are design artifacts. Passing their static/data checks does not close these native release gates.
