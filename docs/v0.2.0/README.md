Keep the current Tidal colors as the default. Add ten familiar developer-theme families, glass chrome with accessible opaque fallbacks, smooth stateful loading/welcome motion, a source-backed context window and Hidden/Compact/Expanded reasoning display. Retain the project/folder/model/effort and rich-content renderer requirements in DESIGN.md.

The owner-held handoff ZIP additionally includes an offline interactive exhibit, vector source, complete theme board, historical source material and the original user references. The public snapshot uses authored fixture screens and excludes the uploaded personal screenshots.

Examples are visual references, not evidence of a passing server action, a real token measurement or native performance. Read DESIGN.md and the acceptance checklist before implementing from a picture.
