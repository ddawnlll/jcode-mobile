01 / Premise Server → phone

The work runs on your server. Ziran is how you return.

Adapter v4 is one Rust process beside JCode. It opens bounded native session links, applies the exact model and effort route, keeps a durable SQLite event journal with cursor replay, and serves an authenticated WebSocket. Ziran speaks that protocol natively in Kotlin and Jetpack Compose—no WebView, no wrapper, no second agent.

Navigation, backgrounding, socket close, and force-quit are never cancellation. Only the explicit Stop control targets the current turn. When you reopen, Ziran restores the exact server and session, or shows an honest recovery state.

04 / Setup Server first

Three moves. One server.

The phone cannot start work on its own. Run JCode and Adapter v4 on your Linux server behind TLS, then pair Ziran with a one-time code or `ziran://pair` link.

Prerequisite / JCode daemon + Rust + TLS

  1. 01

    Build and run Adapter v4.

    One Rust binary speaks the mobile WebSocket and the native JCode session link. It does not run a second agent.

    cargo build --release -p adapter-server --bin jcode-adapter-v4

JCODE_ADAPTER_ALLOWED_ROOTS="$HOME/src" \
JCODE_ADAPTER_BIND=127.0.0.1:7646 \
./target/release/jcode-adapter-v4

    Put a TLS reverse proxy in front of the adapter. Never expose plain ws:// to the internet.

  2. 02

    Read the pairing code.

    The adapter prints a single-use code valid for ten minutes, or use a `ziran://pair` link to fill both fields at once.

    Pairing code (valid for 10 minutes, single use):
K7QM-P2XA-9B4C

    The code is exchanged once for a device token stored in Android Keystore.

  3. 03

    Install and pair Ziran.

    Sideload the native Android APK, enter your HTTPS server address and one-time code, and press the indigo seal.

    adb install -r ziran-0.7.4-android-release.apk

    Read the full setup and TLS notes
